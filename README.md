# React Front-End Developer Interview Task

Build a small **Issue Tracker** UI in React using the requirements below.

## Requirements Summary
- Functional components + hooks.
- Use INITIAL_ISSUES from `issuesData.js`.
- Implement issue list, detail view, search, filters, sorting.
- Implement create/edit issue form.
- No backend; all in-memory.
- Structure your code into components.

## Instructions
Import the data from:
```
import { INITIAL_ISSUES } from "./issuesData";
```

Then build the full UI according to the specification.
